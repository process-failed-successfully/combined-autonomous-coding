options:
  -h, --help            show this help message and exit

Core Configuration:
  --version             Print the agent version and exit.
  --profile PROFILE     Select a configuration profile from agent_config.yaml.
  -p PROJECT_DIR, --project-dir PROJECT_DIR
                        Directory where the project will be created/modified
                        (default: current directory)
  -a {gemini,cursor,local,openrouter}, --agent {gemini,cursor,local,openrouter}
                        Which agent to use (default: gemini)
  -m MODEL, --model MODEL
                        Model to use (overrides default). Can also be set via
                        config.
  -s SPEC, --spec SPEC  Path to app_spec.txt (required for new projects)
  -v, --verbose         Enable verbose logging

Execution Control:
  --max-iterations MAX_ITERATIONS
                        Maximum number of agent iterations. Can also be set
                        via config.
  --timeout TIMEOUT     Timeout in seconds for agent execution (default:
                        600.0). Can also be set via config.
  --max-error-wait MAX_ERROR_WAIT
                        Maximum wait time in seconds for agent error backoff
                        (default: 600.0). Can also be set via config.
  --no-stream           Disable streaming output

Manager Agent:
  --manager-frequency MANAGER_FREQUENCY
                        How often the manager agent runs (default: 10
                        iterations). Can also be set via config.
  --manager-model MANAGER_MODEL
                        Model to use for the manager agent. Can also be set
                        via config.
  --manager-first       Run the manager agent before the first coding session

Dashboard:
  --no-dashboard        Disable the standalone dashboard server (enabled by
                        default)
  --dashboard-url DASHBOARD_URL
                        URL of the dashboard server (default:
                        http://localhost:7654)
  --login               Run the agent in login/authentication mode (exit after
                        login)

Sprint Mode:
  --sprint              Run in Sprint Mode (Concurrent Agents)
  --max-agents MAX_AGENTS
                        Maximum number of simultaneous agents in Sprint Mode.
                        Can also be set via config.

Jira Integration:
  --jira-ticket JIRA_TICKET
                        Jira ticket ID to work on (e.g., PROJ-123)
  --jira-label JIRA_LABEL
                        Jira label to search for (picks first 'To Do' ticket)

Advanced:
  --verify-creation     Run verification test (dummy mode)
  --dind, --docker-in-docker
                        Enable Docker-in-Docker support (mounts docker
                        socket). Can also be set via config.
  --dry-run             DEPRECATED: Use the 'show-config' command instead.
                        Prints the final configuration and exits.
